Podcast front-end HTML and selector reference

Each block documents one visitor-facing output. Example names, addresses, media URLs and durations are synthetic. Renderer-owned classes and data attributes retain their runtime names. WordPress image markup and Elementor template interiors vary with the site.

Listen · Watch · Host cards · Guest cards · Guest directory · Player bar

Listen button

[smp_listen_button post_id="123" label="Listen" class=""]. One usable episode produces one accessible button.

<button type="button" class="smp-listen-button" data-smp-player-trigger
  data-smp-post-id="123" data-smp-audio-src="https://example.test/audio.mp3"
  data-smp-download-src="https://example.test/download.mp3" data-smp-title="Example episode"
  data-smp-url="https://example.test/episode/" data-smp-image="https://example.test/cover.jpg"
  data-smp-duration="12:30" data-smp-duration-seconds="750"
  data-smp-video-id="yzMcrZCYh5Y" data-smp-video-url="https://www.youtube.com/watch?v=yzMcrZCYh5Y"
  aria-controls="smp-podcast-player" aria-pressed="false" aria-label="Listen: Example episode">
  <span data-smp-listen-icon aria-hidden="true"><svg viewBox="0 0 24 24" focusable="false"><path d="M8 5v14l11-7z"/></svg></span>
  <span data-smp-listen-label>Listen</span>
</button>

Style .smp-listen-button; custom class tokens append to it. The runtime updates aria-pressed, the label and icon. Video attributes appear only when the episode has valid video. Missing audio produces no button. A successful render requests player assets.

Renderer: src/Frontend/ShortcodeCallbacks.php.

Watch button

[smp_watch_button post_id="123" label="Watch" element="a"]. The default is a crawlable YouTube anchor.

<a href="https://www.youtube.com/watch?v=yzMcrZCYh5Y" class="smp-watch-button"
  data-smp-watch-trigger data-smp-post-id="123" data-smp-video-id="yzMcrZCYh5Y"
  data-smp-video-url="https://www.youtube.com/watch?v=yzMcrZCYh5Y"
  data-smp-audio-src="https://example.test/audio.mp3" data-smp-download-src="https://example.test/download.mp3"
  data-smp-title="Example episode" data-smp-url="https://example.test/episode/"
  data-smp-image="https://example.test/cover.jpg" data-smp-duration="12:30" data-smp-duration-seconds="750"
  aria-controls="smp-podcast-player" aria-label="Watch: Example episode">
  <span data-smp-watch-label>Watch</span>
</a>

Style .smp-watch-button and [data-smp-watch-label]. This short excerpt omits the decorative span[data-smp-watch-icon] > svg > path that precedes the label. element="button" substitutes a button with type="button" aria-pressed="false" and no href. Audio attributes are conditional; absent valid video returns empty output.

Renderer: src/Frontend/ShortcodeCallbacks.php.

Host profile cards

[display_host_profile_info post_id="123"] renders profile-post cards from the episode hosts relationship.

<div class="host-profile-wrapper smp-podcast-profile-grid">
  <article class="host-profile smp-podcast-person-card">
    <a href="https://example.test/profile/example-host/">
      <img src="https://example.test/host.jpg" alt="Example Host" loading="lazy">
      <h3>Example Host</h3>
    </a>
  </article>
</div>

The grid wrapper controls layout; .host-profile, .smp-podcast-person-card, its image, heading and link control the card. WordPress supplies the actual thumbnail image attributes, or the profile author avatar as fallback. Missing hosts return <p>No host information available.</p>. The first card output emits style#smp-podcast-shortcodes-css once.

Renderer: src/Frontend/ShortcodeCallbacks.php.

Episode host template wrapper

[display_single_episode_hosts post_id="123" must_have_thumbnail="false"] renders Elementor template 20001 for each host; the existing filter can choose another template.

<div class="display_single_episode_hosts">
  <div class="shortcode">
    <article class="host-profile smp-podcast-person-card">
      <a href="https://example.test/profile/example-host/">
        <img src="https://example.test/host.jpg" alt="Example Host" loading="lazy">
        <h3>Example Host</h3>
      </a>
    </article>
  </div>
</div>

This block shows the real profile-card fallback when Elementor has no rendered template. A successful Elementor template replaces the article inside .shortcode; its own classes depend on that saved template. smp_podcast_host_template_id changes the template ID. No hosts return an empty string.

Renderer: src/Frontend/ShortcodeCallbacks.php.

Guest user cards

[display_guest_profile_info post_id="123"] renders legacy WordPress-user guests from repeater rows, including the historical raw-meta fallback.

<div class="guest-profile-wrapper smp-podcast-profile-grid">
  <article class="guest-profile smp-podcast-person-card">
    <div class="guest-photo"><img src="https://example.test/avatar.jpg" alt="Example Guest" width="160" height="160"></div>
    <h3>Example Guest</h3>
    <div class="guest-socials">
      <p>Email: <a href="mailto:guest@example.test">guest@example.test</a></p>
      <p>Website: <a href="https://example.test/guest/" target="_blank" rel="noopener noreferrer">https://example.test/guest/</a></p>
      <p>Linkedin: <a href="https://example.test/linkedin/" target="_blank" rel="noopener noreferrer">https://example.test/linkedin/</a></p>
    </div>
  </article>
</div>

Style .guest-profile-wrapper, .guest-profile, .guest-photo and .guest-socials. Email, website and each social paragraph appear only when populated. Socials cover facebook, linkedin, x, youtube, instagram, soundcloud and tiktok. WordPress supplies avatar attributes. Missing guests return <p>No guest information available.</p>. These guests are users, not Verified Profile posts.

Renderer: src/Frontend/ShortcodeCallbacks.php.

Guest directory

[guest_grid] lists WordPress users in the supported roles, ordered by display name.

<div class="user-grid smp-podcast-user-grid">
  <article class="user-card smp-podcast-person-card">
    <img src="https://example.test/avatar.jpg" alt="Example Guest" width="160" height="160">
    <h3>Example Guest</h3>
    <a class="view-member-button" href="https://example.test/author/example-guest/">View Member</a>
  </article>
</div>

Style .smp-podcast-user-grid for the grid and .user-card, .smp-podcast-person-card and .view-member-button for each entry. WordPress supplies avatar markup. With no users the shortcode returns empty. The shared shortcode stylesheet uses six columns, three at 1024px and two at 640px.

Renderer: src/Frontend/ShortcodeCallbacks.php.

Persistent player bar

An enabled player appears once on the homepage, an episode, or a request that outputs a usable Listen/Watch control. This structural excerpt uses the actual container and control classes; decorative SVG paths and repeated select options are omitted.

<aside id="smp-podcast-player" class="smp-podcast-player" data-smp-player data-smp-mode="audio" hidden aria-label="Persistent podcast media player">
  <audio data-smp-audio preload="metadata"></audio>
  <div class="smp-podcast-player__inner">
    <div class="smp-podcast-player__identity">
      <div class="smp-podcast-player__stage" data-smp-stage>
        <div data-smp-video-shell class="smp-podcast-player__video" hidden>
          <iframe data-smp-video title="Episode video" allow="autoplay; encrypted-media; picture-in-picture" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe>
        </div>
      </div>
      <div class="smp-podcast-player__copy">
        <span class="smp-podcast-player__eyebrow">Now playing / <span data-smp-kind>Audio</span></span>
        <a data-smp-title class="smp-podcast-player__title">Select an episode</a>
        <div class="smp-podcast-player__modes" data-smp-modes role="group" aria-label="Playback format">
          <button type="button" data-smp-mode-button="audio" class="smp-podcast-player__mode is-active" aria-pressed="true">Audio</button>
          <button type="button" data-smp-mode-button="video" class="smp-podcast-player__mode" aria-pressed="false">Video</button>
        </div>
      </div>
    </div>
    <div class="smp-podcast-player__transport">
      <div class="smp-podcast-player__buttons">
        <button type="button" data-smp-back class="smp-podcast-player__button smp-podcast-player__skip" aria-label="Skip backward 15 seconds"><small>15</small></button>
        <button type="button" data-smp-toggle class="smp-podcast-player__button smp-podcast-player__toggle" aria-label="Play episode" aria-pressed="false"></button>
        <button type="button" data-smp-forward class="smp-podcast-player__button smp-podcast-player__skip" aria-label="Skip forward 30 seconds"><small>30</small></button>
      </div>
      <div class="smp-podcast-player__timeline">
        <span data-smp-elapsed>0:00</span>
        <label class="screen-reader-text" for="smp-podcast-seek">Episode position</label>
        <input id="smp-podcast-seek" data-smp-seek type="range" min="0" max="1" step="0.1" value="0" aria-valuetext="0 minutes 0 seconds">
        <span data-smp-duration>0:00</span>
      </div>
    </div>
    <div class="smp-podcast-player__utilities">
      <label class="smp-podcast-player__rate"><span class="screen-reader-text">Playback speed</span><select data-smp-rate aria-label="Playback speed"><option value="1" selected>1×</option></select></label>
      <div class="smp-podcast-player__volume">
        <button type="button" data-smp-mute class="smp-podcast-player__utility" aria-label="Mute audio" aria-pressed="false"></button>
        <label class="screen-reader-text" for="smp-podcast-volume">Volume</label>
        <input id="smp-podcast-volume" data-smp-volume type="range" min="0" max="1" step="0.05" value="1">
      </div>
      <a data-smp-download class="smp-podcast-player__utility smp-podcast-player__download" href="#" download aria-label="Download episode"></a>
      <button type="button" data-smp-close class="smp-podcast-player__utility smp-podcast-player__close" aria-label="Close player"></button>
    </div>
  </div>
  <span data-smp-status class="screen-reader-text" aria-live="polite"></span>
</aside>

assets/frontend-player.css owns bar layout and reduced-motion rules. data-smp-mode changes between audio/video, mode buttons toggle .is-active, and body.smp-podcast-player-visible reserves space. The bar starts hidden with no empty artwork image; a selected track creates the cover image. Disabled optional controls receive hidden. Timing, labels, artwork and media URLs come from the episode/settings, not this example. The footer can print late shortcode styles once.

Renderer: src/Frontend/PersistentPlayer.php; assets/frontend-player.css; assets/frontend-player.js.

Host and guest relationship links

[podcast_hosts] and [article_guests] render comma-separated profile-post links.

<span class="shortcode_podcast_hosts"><a href="https://example.test/profile/host/">Example Host</a></span>
<span class="shortcode_article_guests"><a href="https://example.test/profile/guest/">Example Guest</a></span>

The two span classes are the intended styling hooks. Empty relationships return empty strings, without global CSS.

Renderer: src/Frontend/ShortcodeCallbacks.php.

Homepage interactions

Homepage behavior attaches to the existing Elementor homepage, rather than creating a new page wrapper.

<div class="mpp-topic-chip">
  <a class="elementor-button" href="#" data-topic="technology" aria-pressed="false">
    <span class="elementor-button-text">Technology</span>
  </a>
</div>

This is a selector example; the existing saved homepage supplies its actual attributes and layout. See assets/home-interactions.js for the exact topic, filter and scroll-cue bindings. Both home-interactions assets load only on is_front_page().

Renderer: src/Frontend/HomeInteractions.php.
