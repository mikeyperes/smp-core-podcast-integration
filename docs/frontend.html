Podcast front-end markup

Illustrative values; structures and selectors are owned by src/Frontend/ShortcodeCallbacks.php. Existing site styling remains authoritative.

Media controls

<button type="button" class="smp-listen-button" data-smp-player-trigger data-smp-post-id="123" data-smp-audio-src="https://example.test/episode.mp3" data-smp-download-src="https://example.test/episode.mp3" data-smp-title="Example episode" data-smp-url="https://example.test/episode/" aria-controls="smp-podcast-player" aria-pressed="false"><span data-smp-listen-label>Listen</span></button>
<a href="https://www.youtube.com/watch?v=yzMcrZCYh5Y" class="smp-watch-button" data-smp-watch-trigger data-smp-video-id="yzMcrZCYh5Y" aria-controls="smp-podcast-player"><span data-smp-watch-label>Watch</span></a>

Use .smp-listen-button and .smp-watch-button for button styling; [aria-pressed] reflects playback on button controls. See the full emitted source for optional audio/video/artwork/duration attributes and SVG icons.

The profile grids, .smp-podcast-person-card, .guest-profile and .view-member-button are the styling selectors. Empty profiles return the existing explanatory paragraph.

Persistent player

src/Frontend/PersistentPlayer.php owns #smp-podcast-player, .smp-podcast-player and [data-smp-stage]. assets/frontend-player.css styles its controls, active audio/video states and reduced-motion behavior. The initial player has no artwork until a track is selected.

Scalar fields and URLs

podcast_url, episode_fields and podcast_host return escaped scalar values or their existing permitted biography HTML without an extra wrapper.
